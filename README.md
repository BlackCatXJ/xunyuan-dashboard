# 循源 · 京津冀资源循环大屏

REV-015 视觉优化版。纯 HTML/CSS/JavaScript 静态演示，使用 GitHub Pages 发布。

全部业务数据、设施和预测为 Mock；地图为关系示意，区县候选名录未逐项核验。无真实业务系统接入。

建议以 1920×1080 浏览器全屏演示。支持资源分布、月度预测、协同调配、网络布局、资源链与决策摘要。

本地启动：`python3 -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765/index.html#/overview`。

GitHub Pages：Settings → Pages → Deploy from a branch → main / (root)。

区县名录许可说明见 `data/source/`。
